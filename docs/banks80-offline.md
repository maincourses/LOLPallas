## 实现与变化隔离

新增源码 `tools/native/library80-banks.c` 重用既有 `library20.c` 的 64 KiB 读取器、固定路径、长度/FNV、临时堆和 Win32 I/O；没有新导入、可写 PE 节、后台进程或独立热键监听器。原键盘回调保留面板开启/按住条件、主键防重复、发送函数和十个统计计数槽，只将两处键位归一化 CALL 指向分组适配器。

原初始化向量和接收向量分配 81 个已构造字符串，JSON 只解析八十条。额外第 81 个槽位保存合法短字符串 `"00"`，表示当前组和翻页按键锁存；不挪用未知控制器字段，也不增加 RW 全局变量。接收索引推广至八个十条段，保持前二十条原来的槽位映射。适配器保留原调用约定中的事件／键位寄存器，提供标准 Win64 shadow space 和栈展开信息。

原生发送前增加有效 UTF-8／100 UTF-16 单位检查；通过后仍调用原 `0x180019F98` 发送入口，不模拟输入、不拼包、不修改游戏服务器限制。失败读取明确清空全部八十条，避免再次接收时残留后六十条旧文本；空文本及超长／坏编码均不调用原发送。此八十条空方案仅由条件编译启用，默认旧版仍逐字节复现已成功的 DLL。

# LOLPallas 分享测试版

64 KiB 本地文案库，1～512 条消息，每条可设独立组合键。只适用于 **64 位 Windows、有国服 WeGame 的电脑**。解压后的文件夹可放在其他盘符、中文或带空格的目录；无需 Python、编译器或 Codex。

**这是尚未完成游戏内验证的实验包，不是官方 WeGame 功能。** 离线测试通过不代表任意电脑、任意 WeGame 版本都可用。它修改 WeGame 的喊话组件并使该组件的签名摘要失效，可能导致拒绝加载、更新覆盖或异常；不能保证账号或运行风险为零。遇到安全、签名、完整性或反作弊提示，请停止并还原，不关闭或绕过保护。

## 第一次用

1. 将 ZIP **全部解压**到普通可写文件夹，不要在压缩包内部直接运行，也不要放进 WeGame 安装目录。
2. 结束对局，关闭英雄联盟和客户端，从系统托盘彻底退出 WeGame。
3. 双击 `Install.cmd`。它会自动查找 WeGame；找不到或找到多个时，选择包含 `apps\Pallas` 的 **WeGame 安装文件夹**，不是英雄联盟目录。
4. 阅读风险提示；同意后输入大写 `YES`。若出现管理员提示，允许同一 Windows 用户的正常提权；不要改用另一个用户账号。
5. 确认结果为 `INSTALLED AND READ BACK`。双击 `Open-Editor.cmd` 修改文案和键位，点击“保存并应用”。应用时也要退出游戏、客户端和 WeGame。
6. 手动启动 WeGame，开启英雄联盟助手中的“一键喊话”；在训练模式先用短消息测试。默认前十条为 `~+1～9、0`，后十条为 `~+F1～F10`。再测试一条 `Ctrl+Alt+Q` 之类的独立组合。`~` 指 Esc 下方、数字 1 左边的实体按键，不需要按 Shift。

按住修饰键，按下主键发送一次；只松开主键就可以再次发送，不会自动连发。快捷键**不会屏蔽游戏原来的按键**，请避开与游戏操作冲突的组合。

文案请在本地编辑器中管理，**不再在 WeGame 原生助手内编辑**。原生面板不展示全部消息和独立组合键，不能据其显示判断本地库是否生效。

修复版恢复原生前十个 ~+数字槽位的预览。切换窗口后若仍按住快捷键，请先松开再按，恢复焦点不会自动重发。旧 v3 用户也需要退出游戏和 WeGame 后运行新版 `Install.cmd` 升级；升级保留已应用文案、键位及最初还原备份，仅保存文案不会更新组件。

安装器支持已核验的固定组件版本。若显示 `Unsupported ... build`，它不会强制替换：保留错误窗口中的 SHA256，交给维护者分析。不要把其他电脑的 DLL、AppData 备份或账号文件复制过来。WeGame 更新后也需要重新核验，而不是反复强装。

## 文件和按钮

- `Install.cmd`：首次安装、升级已核验的旧 v3，也可在成功还原后重新启用；先备份，不改 Pallas 启动器。
- `Open-Editor.cmd`：编辑内容和键位，增删消息、录制快捷键。
- `Check.cmd`：只读检查安装位置、文件一致性及状态；可在 WeGame 运行时检查。
- `Restore.cmd`：退出 WeGame 和游戏后，恢复本机安装前的组件，保留文案和所有备份。
- `Choose-WeGame.cmd`：手动选择 WeGame 安装文件夹后进入安装。
- `messages.example.json`：公共默认文案；**不含包制作者的私人文案**。
- `messages.json`：首次打开编辑器生成的个人可编辑文案。安装后即使重新解压一份包，首次打开编辑器也能从已应用的本地文案恢复，不覆盖已有 `messages.json`。
- `*.ps1`、`lib/`：界面、检测、校验、安装和还原实现；不要单独删除。
- `patches/`：仅针对已核验组件的二进制差异数据，不是可单独运行的程序；接收者本机重建候选组件。
- `package-manifest.json`：文件清单、校验值和验证边界。

“保存文案”只写 `messages.json`，可在 WeGame 运行时使用；“保存并应用”还会生成运行库，要求完全退出游戏和 WeGame。只保存、未应用，运行内容不会改变。

个人运行库、已应用源文案、安装记录和原组件备份位于当前用户的 `%LOCALAPPDATA%\LOLPallasPortable`。安装失败也保留已准备的文案和备份，不删除它们。成功还原后的重新安装沿用上次已应用文案，不用包内默认内容覆盖。失败／不完整的安装记录可能需要人工复核，不能盲目删除记录或强装。

## 容量和兼容边界

整库最多 65536 字节（含 20 字节头、每条 9 字节元数据和 UTF-8 文案），最多 512 条；不能保证 512 条全写满。单条仍保护为 **50 个 UTF-16 单位**，普通汉字通常算 1，部分 emoji 算 2；超过拒绝保存，不截断。不是已测得的服务器上限，也没有解除游戏的单条限制。

本地加载不依赖上传自定义文案到云端；WeGame 登录和其他原有功能仍可能联网。此包不读取账号票据、不模拟逐字输入、不自动发送消息，也不向游戏进程进行运行时注入。功能依赖 WeGame 原有喊话回调与发送链路。**首次在原版启动器／新电脑上加载、真实游戏发送、独立组合键，目前仍需人工验证。**

不同 Windows 用户有不同本地库。暂不支持同一机器多用户同时共用安装、UNC 网络目录、链接／重解析安装目录，或超过传统 MAX_PATH 的运行库路径。未知版本拒绝覆盖，更新后的组件拒绝盲目还原。还原只撤销此包安装的组件，不替你恢复历史版本的启动器或其他第三方补丁。

如果想转发“干净工具”，请转发原始 ZIP；不要直接压缩你使用后的整个文件夹，其中的 `messages.json`、`backups/` 是你的个人内容。不要分发 AppData 内的组件备份。
